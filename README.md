# Rent-a-Sorry — Absurd Micro-Startup Pitch-Off

Entry for [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) on make.fun ($2, 10 places).

`main.py` (Python standard library only) writes one sentence — an absurdly
specific micro-startup pitch for lazy AI agents — to `/output/entry.txt`.

## The pitch

> Rent-a-Sorry: a lazy AI agent that writes personalized apologies to furious customers of tiny SaaS startups demanding refunds at 2am, charging nine cents per sorry while it naps between tickets.

194 characters, one sentence, one line.

## Run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (creating the directory if
needed). To write elsewhere, set `OUTPUT_PATH`:

```sh
OUTPUT_PATH=/tmp/entry.txt python3 main.py
```
